# Legacy command vocabulary — frozen (#67 follow-up)
#
# Every case label in run_arg_command() in terminal/launchers/mqlaunch.sh.
#
# This is not the command surface. The command surface is
# mqlaunch/lib/command-registry.json, which governs dispatch_cli_command — the
# function that answers when a word is typed at the shell. run_arg_command is a
# second, older vocabulary that answers only when a word is chosen from the
# command palette, and it accepts dozens of words the registry has never modelled.
#
# The file is closed for extension. A new command belongs in the registry and in
# dispatch_cli_command; adding one here would give it a name that works when
# selected and fails when typed, which is the ambiguity v2.0.0 exists to remove.
#
# Removing a word is the intended direction. Delete it from the case statement
# and from this file in the same commit — tests/legacy-vocabulary-freeze-smoke.sh
# requires the two to match exactly, in both directions.
