Repo state, CI and release readiness in one menu.

mqlaunch hal collects repo state, CI, doctor results and release readiness in one terminal menu. Results are kept in HAL’s local session memory. The one choice that sends data off your Mac is marked in red.

What you get back

Output captured from macos-scripts 2.6.0. Fix plan suggests commands; nothing runs until you type them.

Before you open HAL

The menu is a thin bridge: mqlaunch owns UX, mq-hal owns the logic. The menu is drawn with the same surface_* helpers as the rest of mqlaunch.

mq-hal backend

Expected at ~/mq-hal/bin/mq-hal. Without it the menu shows where it looked.

GitHub access

CI status reads recent workflow runs from GitHub.

Ollama (optional)

Local model used by Fix plan and Prompt.
